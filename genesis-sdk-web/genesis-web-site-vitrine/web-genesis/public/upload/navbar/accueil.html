tout le socle, déjà écrit

Pour chaque table, vous obtenez l’entité, le DTO, le repository, le service et le contrôleur, rangés comme il faut. Vous ouvrez le projet, il compile, et vous passez directement à la logique métier.

Voir un projet généré

Votre table

email VARCHAR(150) NOT NULL

Le code généré

@NotNull(message = "email est obligatoire")
@Size(max = 150)
@Column(name = "email")
private String email;

vos règles, gardées

Les contraintes de votre base deviennent des règles de validation dans le code. Un champ obligatoire reste obligatoire, une longueur maximale reste respectée. Rien à recopier à la main.
