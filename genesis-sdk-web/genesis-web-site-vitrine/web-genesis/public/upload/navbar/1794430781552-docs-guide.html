Comment utiliser Genesis dans IntelliJ IDEA, de l’ouverture de l’assistant jusqu’au lancement du projet généré.

Utilisation

Il y a deux façons d’ouvrir Genesis dans IntelliJ IDEA, selon que vous partez de zéro ou d’un projet existant.

Créer un nouveau projet

Allez dans File › New › Project…, choisissez Genesis dans la liste à gauche et suivez l’assistant. À la fin, cliquez sur Create.

Générer dans un projet existant

Ouvrez votre projet, puis Tools › Genesis Project Generator. Le même assistant s’ouvre, et vous choisissez le dossier où le code sera écrit. C’est pratique pour ajouter du code sans créer un nouveau projet.

Tutoriel : de la base de données à l’API

  1. Initialisation

    Choisissez le langage (Java ou C#), le framework, par exemple Spring Boot Web API REST, et le dossier de sortie.

  2. Connexion à la base

    Indiquez l’hôte, le port, le nom de la base et vos identifiants, puis testez la connexion. Pas encore de base ? Décrivez vos tables et l’IA écrit le SQL.

  3. Sélection

    Cochez les tables et les vues que vous voulez dans le projet.

  4. Configuration

    Réglez le port, la sécurité et le frontend (React, Angular ou Vue). Vous pouvez aussi changer les couleurs, le logo et le favicon.

  5. Génération et lancement

    Cliquez sur Create, puis lancez le projet.

# Spring Boot
./mvnw spring-boot:run

# ASP.NET Core
dotnet run

# Frontend (React, Vue ou Angular)
npm install && npm run dev

Swagger par framework

Chaque API générée a sa documentation Swagger, disponible dès le premier démarrage.

FrameworkBibliothèqueAdresse
Spring Boot Web API RESTspringdoc-openapi/swagger-ui/index.html (on y arrive aussi depuis /)
ASP.NET Core Web API RESTSwashbuckle.AspNetCore 6.9/swagger
NestJS Web API@nestjs/swagger/api

Les projets ASP.NET Core MVC n’ont pas de Swagger : ils affichent directement des pages Razor.

Utilisation token IA

Si vous n’avez pas encore de base, Genesis peut écrire le script SQL à partir d’une simple description. Pour ça, il passe par l’API Groq, et c’est le seul moment où des tokens sont utilisés. La génération du code, elle, se fait entièrement sur votre machine.

Modèles disponibles
llama3-8b-8192
llama3-70b-8192
llama-3.1-8b-instant
openai/gpt-oss-120b

Ajoutez votre clé dans la configuration. Vous trouverez un exemple dans genesis-core/llm.http.example :

POST https://api.groq.com/openai/v1/chat/completions
Authorization: Bearer <YOUR_GROQ_TOKEN_HERE>
Content-Type: application/json

Gardez votre clé en dehors de Git, par exemple dans une variable d’environnement.
