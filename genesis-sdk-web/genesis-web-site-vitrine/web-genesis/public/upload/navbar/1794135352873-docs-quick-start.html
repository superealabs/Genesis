Genesis part de votre base de données pour créer un projet complet, backend et frontend. Cette page vous aide à l’installer et à faire un premier essai.

Introduction

Une fois connecté à votre base, Genesis écrit pour vous :

  • les modèles, une classe par table (entités JPA ou classes C#) ;
  • les contrôleurs, les repositories et les services ;
  • les écrans pour consulter et modifier vos données (React, Angular, Vue ou Razor) ;
  • les fichiers de configuration (application.properties, appsettings.json…) ;
  • la sécurité et la validation, reprise de vos contraintes SQL.

Vous pouvez l’utiliser comme plugin IntelliJ IDEA ou en ligne de commande.

Installation

# 1. Cloner le projet
git clone https://github.com/superealabs/Genesis.git
cd Genesis

# 2. Construire
gradle clean build -x test

# 3a. Lancer un IDE avec le plugin (mode développement)
gradle genesis-intellij:runIde

# 3b. Ou construire le plugin (.zip dans genesis-intellij/build/distributions/)
gradle genesis-intellij:buildPlugin

# 3c. Ou utiliser la CLI
gradle genesis-cli:shadowJar
java -jar genesis-cli/build/libs/genesis-cli-0.0.1.jar

Pour installer le plugin à partir du fichier .zip, passez par Settings › Plugins › ⚙ › Install Plugin from Disk…, puis redémarrez IntelliJ.
