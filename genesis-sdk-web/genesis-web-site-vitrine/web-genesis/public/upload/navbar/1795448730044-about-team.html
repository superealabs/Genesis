Genesis est parti d’une frustration : d’un projet à l’autre, on réécrivait sans arrêt le même code de base. On a voulu faire gagner ce temps aux développeurs, donner aux étudiants des exemples de code propre, et construire un outil ouvert où tout le monde peut participer.

Notre histoire

Le projet a démarré en février 2025, avec une première version (v0.0.1) sortie dans la foulée. Depuis, une douzaine de personnes y ont contribué, pour près de 1 500 commits. L’outil est toujours gratuit et fonctionne entièrement sur votre machine.

Pour les pros

Démarrer une API ou des microservices sans passer des jours sur la configuration.

Pour les étudiants

Voir à quoi ressemble un projet bien organisé (Clean Code, SOLID) et apprendre en le lisant.

Pour les curieux

Lire le code, le modifier et proposer vos améliorations.
