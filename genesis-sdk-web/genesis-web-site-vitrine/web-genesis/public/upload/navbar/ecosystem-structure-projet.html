Voici à quoi ressemble un projet généré, pour un projet MonProjet avec une seule table client.

Backend

MonProjet/ ├── pom.xml · mvnw · .gitignore └── src/main/ ├── java/com/genesis/monprojet/ │ ├── config/ # OpenAPI, sécurité, CORS │ ├── controllers/ # un contrôleur REST par table │ ├── models/ # entités JPA │ │ └── dto/ │ ├── repositories/ # Spring Data JPA │ ├── services/ │ │ └── interfaces/ │ ├── specification/ # filtres dynamiques │ ├── exception/handler/ │ └── utils/ └── resources/ └── application.yml
MonProjet/ ├── MonProjet/ │ ├── Controllers/ │ ├── Data/ # DbContext Entity Framework │ ├── Models/ │ │ └── Dto/ │ ├── Repositories/ │ │ ├── Generic/ · Interface/ · Implementation/ │ ├── Services/ │ │ ├── Generic/ · Interface/ · Implementation/ │ ├── Specification/ · Filters/ · Exceptions/ │ ├── Serialization/ · Utils/ │ ├── Program.cs │ └── appsettings.json └── MonProjet.Tests/
MonProjet/ ├── Controllers/ ├── Data/ ├── Models/ │ └── Dto/ ├── ViewModels/ ├── Views/ │ ├── Client/ # Index, Details, Create, Edit │ └── Shared/ # layout, navbar ├── Repositories/ · Services/ ├── Specification/ · Filters/ · Exceptions/ · Utils/ └── wwwroot/ └── images/
MonGateway/ # Spring Cloud Gateway ├── pom.xml └── src/main/ ├── java/…/config/ │ └── SecurityConfig.java └── resources/ └── application.yml # routes, URL Eureka MonDiscovery/ # Eureka Server └── src/main/resources/ └── application.yml

Pour chaque table, vous obtenez une entité, un DTO, un repository, un service (interface et implémentation) et un contrôleur.

Frontend

frontend/ ├── package.json · vite.config.ts · tsconfig.json ├── public/ └── src/ ├── pages/ │ ├── client/ # liste, détail, formulaire │ └── auth/ ├── models/client/ ├── services/ # appels API ├── router/ · layouts/ · contexts/ ├── components/SettingsMenu/ ├── locales/ # i18n └── config/
frontend/ ├── angular.json · package.json └── src/ ├── app/ │ ├── features/ │ │ ├── client/ │ │ │ ├── client-list/ · client-details/ │ │ │ ├── client-form/ · client-table-form/ │ │ │ ├── models/ │ │ │ └── services/ │ │ └── authentication/ │ └── shared/ ├── assets/ · environments/ ├── lang/ └── utilities/
frontend/ ├── package.json · vite.config.ts · tailwind.config.js ├── public/ └── src/ ├── views/ │ ├── client/ │ └── auth/ ├── entities/client/ ├── models/ · models/validators/ ├── services/ · stores/ · composables/ ├── router/entities/ ├── components/ # navbar, button, auth, user ├── layouts/ · lang/ └── config/

Chaque table a sa liste (tri, filtres, pagination), sa page de détail, son formulaire, et une confirmation avant suppression.
