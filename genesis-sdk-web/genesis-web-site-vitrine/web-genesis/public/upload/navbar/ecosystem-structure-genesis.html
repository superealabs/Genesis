Genesis est découpé en trois modules Gradle. Le moteur, genesis-core, fait tout le travail. Les deux autres sont simplement deux façons de l’utiliser.

Structure

Genesis/ ├── genesis-core/ # moteur de génération ├── genesis-cli/ # interface en ligne de commande ├── genesis-intellij/ # plugin IntelliJ IDEA ├── docs/ ├── sample-db/ # bases d’exemple ├── build.gradle.kts ├── settings.gradle.kts └── README.md

genesis-core

Le moteur : il lit la base, applique les templates et écrit les fichiers.

genesis-cli

Pose les questions dans le terminal et lance la génération.

genesis-intellij

L’assistant dans IntelliJ IDEA : choix de la base, aperçu des tables, réglages.

genesis-core

genesis-core/src/main/java/org/labs/genesis/ ├── config/ # ProjectGenerationContext, Constantes, database, langage, git ├── connexion/ # Database, Credentials, SQLRunner, ConstraintQueries, providers ├── engine/ # GenesisTemplateEngine (moteur Mustache-like) ├── frontend/ # FrontendLanguage, générateurs frontend ├── merge/ # MergeTool : fusion avec un projet existant ├── remover/ # APIRemover, FrontendRemover └── exceptions/

Ce que Genesis sait générer est décrit dans des fichiers de ressources. On peut donc ajouter un framework sans toucher au moteur :

genesis-core/src/main/resources/data_genesis/ ├── json/ # databases.json, languages.json, llm-api-config.json ├── yaml/ │ ├── frameworks.yaml # Spring Boot, .NET Web API, Gateway, Eureka │ ├── frameworks-mvc.yaml # .NET MVC, Spring MVC, Django MVT │ ├── constraint-queries.yaml # extraction des contraintes SQL │ └── framework-securities.yaml # sécurité par framework ├── frontend/ # squelettes React, Vue, Angular ├── templates/ # Template 1, Template 2 (HTML/CSS/JS) ├── csharp/ · maven/ · django/ └── txt/

genesis-cli

genesis-cli/src/main/java/org/labs/ ├── GenesisCLI.java # point d’entrée └── handler/ └── ProjectGeneratorHandler.java # questions interactives + génération

genesis-intellij

genesis-intellij/src/main/java/org/labs/genesis/ ├── actions/ # GenesisGenerateAction, GenesisWizardDialog (menu Tools) ├── module/ # ModuleBuilder (File › New › Project) ├── wizards/ # étapes de l’assistant ├── forms/ # formulaires Swing ├── config/ide/ # DriverConfig, IdeConfiguration, templates .iml ├── services/ · context/ · listener/ ├── component/ # ConflictFilesDialog └── renderer/ · icon/ · utils/
