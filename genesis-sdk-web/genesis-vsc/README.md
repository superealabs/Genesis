# Genesis Generator

Extension en pré-production pour générer et configurer des projets directement dans Visual Studio Code.

## Fonctionnalités

- **Assistant de configuration (Wizard)** : Interface pas à pas pour définir le framework, la base de données, le frontend et les dépôts Git.
- **Génération assistée par IA** : Intégration d'un assistant pour la génération et l'import de scripts.
- **Tutoriel interactif** : Guide intégré pour prendre en main l'outil rapidement.

## Paramètres de l'extension

Cette extension contribue aux paramètres suivants :

* `genesis.theme` : Thème de l'interface Genesis (`genesis`, `vscode`, `mono`).
* `genesis.colorMode` : Mode de couleur de l'interface (`auto`, `light`, `dark`).
