quand on est sur select, 
on manipule la variable pending, 
quand on est sur la page de config, on manipule la vrai variable,

Ce qui veut dire que :
Si on modifie depuis le select et qu'on ne fait pas suivant, la valeur revient à la valeur déjà configurée, à nul, si non configuré

Si on modifie depuis le config, le select change automatiquement.
