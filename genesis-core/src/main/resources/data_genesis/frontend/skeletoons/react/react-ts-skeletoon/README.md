# Getting Started with Vite + React

This project was bootstrapped with [Vite](https://vitejs.dev/).

> Vite is a fast, opinionated build tool that serves your code via native ES modules during development and bundles it with Rollup for production.

---

## 📦 Prerequisites

- **Node.js** ≥ 18
- **npm** (or **yarn**, **pnpm**, **bun**)

---

## 🚀 Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Start the dev server
npm run dev
